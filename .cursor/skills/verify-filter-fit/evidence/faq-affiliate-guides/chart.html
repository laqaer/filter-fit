Measure twice

Nominal size and slot-depth chart

The number on the box is a name. The number that fits is the actual cardboard. Depth is a third measurement, not a model suffix you can ignore.

How to measure so the pad actually seats

  1. Read the old filter for the nominal (16×25×1). Then measure the cardboard anyway. Brands vary by a quarter inch.
  2. Measure the slot — width, height, and the depth the frame can occupy without bowing the door.
  3. Prefer the smaller actual if you are between sizes. A filter that rattles leaks. A filter you hammer in collapses.
  4. Count the filters. Some systems use one at the furnace and one at a return grille. They are not always the same size.

×1 is depth, not a version number

16×25×1 means a 1-inch-class depth. 16×25×4 is a different product. Ordering the wrong third number is the most common FilterFit support email we expect to get.

Depth classes

  • 1 inch. Retail slide-in. Least media. MERV 13 is the risky upgrade — read MERV 11 vs 13.
  • 2 inch. Extra pleat area, still a throwaway rack. Confirm the door actually closes on 2 inches.
  • 4 inch. The usual aftermarket media cabinet. This is how most homes should run MERV 13. See depth vs MERV.
  • 5 inch. Honeywell-style / deep media. Do not assume a 4-inch pad fills it without the specified spacer.

Things that look like a size and are not

  • A door sticker copied from the last wrong filter someone jammed in.
  • A grille that takes 20×25×1 while the furnace cabinet takes 16×25×1.
  • Oddball “exact” sizes from a custom shop — good, as long as you measured the slot.
  • Washable foam cut from a roll. That is a pad, not a MERV 13 pleated filter.

Questions

Is the size printed on the box the size that fits?

The number on the box is a nominal name. The cardboard that fits is the actual size. Read the old filter, then measure the cardboard. Brands vary by a quarter inch. If the opening sits between two sizes, take the smaller actual. A filter that rattles leaks. A filter that has to be forced in collapses. The table on this page lists usual North American cardboard sizes. Match the spec line on the filter you order, because mills differ.

What does the last number in 16×25×1 mean?

It is slot depth. 16×25×1 means a 1-inch-class depth. 16×25×4 is a different product. Measure the depth the frame can occupy without bowing the door. Ordering the wrong third number is the common mismatch.

How do 1-inch, 2-inch, 4-inch, and 5-inch slots differ?

A 1-inch slot is a retail slide-in with the least media. MERV 13 in that slot is the risky upgrade. See MERV 11 vs 13. A 2-inch rack adds pleat area and is still a throwaway filter. Confirm the door closes on 2 inches. A 4-inch cabinet is the usual aftermarket media cabinet, and the depth most homes should use for MERV 13. See depth vs MERV. A 5-inch cabinet is deep media. Do not assume a 4-inch pad fills it without the specified spacer.

Can the return grille and the furnace take different filters?

Yes. Some systems use one filter at the furnace and one at a return grille, and those two pads are not always the same size. A grille that takes 20×25×1 while the furnace cabinet takes 16×25×1 is a common trap. Count the filters and measure each slot before you order.
